# Starter question packs

These packs are ready for the JSON course-pack loader and can be published as GitHub-backed community packs.

| Pack | Language | Units | Questions per lesson |
| --- | --- | ---: | ---: |
| `kotlin-foundations.json` | Kotlin | 5 | 8 |
| `swift-foundations.json` | Swift | 5 | 8 |
| `react-foundations.json` | React | 5 | 8 |
| `typescript-foundations.json` | TypeScript | 5 | 8 |

Each lesson is intentionally focused on one unit. The mobile curriculum can repeat a concept inside a unit without sharing exercise IDs, which supports retrieval practice and spaced review.

Before publishing a community pack, run the loader with `verifyContentHash: true` and keep the `contentHash` in sync with the canonical payload.
